内网经验总结：Ducc 权限自动确认                                                                                                                                                                              
                                                                                                                                                                                                               
  方法一：/permissions 命令（Boris 推荐，最安全）                                                                                                                                                              
                                                                                                                                                                                                               
  在 Ducc 会话中输入 /permissions，预先批准常用的安全命令，避免每次弹窗。配置自动保存到 .claude/settings.json，可团队共享。                                                                                    
                                                                                                                                                                                                               
  这是 CC 作者 Boris 本人的做法，他明确说不用 --dangerously-skip-permissions，而是用这个方式精细控制。                                                                                                         
                                                                                                                                                                                                               
  ---                                                                                                                                                                                                          
  方法二：启动参数跳过所有确认                                                                                                                                                                                 
                                                                                                                                                                                                               
  ducc --dangerously-skip-permissions                                                                                                                                                                          
                                                                                                                                                                                                               
  或另一个更温和的模式：                                                                                                                                                                                       
                                                                                                                                                                                                               
  ducc --permission-mode=dontAsk                                                                                                                                                                               
                                                                                                                                                                                                               
  ▎ 内网文档建议：仅在 Docker、沙箱或隔离环境中使用。                                                                                                                                                          
                                                                                                                                                                                                               
  ---                                                                                                                                                                                                          
  方法三：设置别名（内网用户实践）                                                                                                                                                                             
                                                                                                                                                                                                               
  有同学直接在 fish/zsh 配置里设置别名：                                                                                                                                                                       
                                                                                                                                                                                                               
  # fish                                                                                                                                                                                                       
  abbr -a cc "ducc --dangerously-skip-permissions"                                                                                                                                                             

  # zsh
  alias cc="ducc --dangerously-skip-permissions"

  之后直接输入 cc 启动即可全自动。

  ---
  方法四：~/.claude/settings.json 配置白名单（我推荐）

  {
    "theme": "auto",
    "permissions": {
      "allow": [
        "Bash(*)",
        "Read(*)",
        "Write(*)",
        "Edit(*)",
        "Glob(*)",
        "Grep(*)"
      ]
    }
  }
