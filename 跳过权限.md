内网经验总结：Ducc 权限自动确认                                                                                                                                                                              
                                                                                                                                                                                                               
  方法一：/permissions 命令（Boris 推荐，最安全）                                                                                                                                                              
                                                                                                                                                                                                               
  在 Ducc 会话中输入 /permissions，预先批准常用的安全命令，避免每次弹窗。配置自动保存到 .claude/settings.json，可团队共享。                                                                                    
                                                                                                                                                                                                               
  这是 CC 作者 Boris 本人的做法，他明确说不用 --dangerously-skip-permissions，而是用这个方式精细控制。                                                                                                         
                                                                                                                                                                                                               
  ---                                                                                                                                                                                                          
  方法二：启动参数跳过所有确认                                                                                                                                                                                 
                                                                                                                                                                                                               
  ducc --dangerously-skip-permissions                                                                                                                                                                          
                                                                                                                                                                                                               
  或另一个更温和的模式：                                                                                                                                                                                       
                                                                                                                                                                                                               
  ducc --permission-mode=dontAsk                                                                                                                                                                               
                                                                                                                                                                                                               
  ▎ 内网文档建议：仅在 Docker、沙箱或隔离环境中使用。                                                                                                                                                          
                                                                                                                                                                                                               
  ---                                                                                                                                                                                                          
  方法三：设置别名（内网用户实践）                                                                                                                                                                             
                                                                                                                                                                                                               
  有同学直接在 fish/zsh 配置里设置别名：                                                                                                                                                                       
                                                                                                                                                                                                               
  # fish                                                                                                                                                                                                       
  abbr -a cc "ducc --dangerously-skip-permissions"                                                                                                                                                             

  # zsh
  alias cc="ducc --dangerously-skip-permissions"

  之后直接输入 cc 启动即可全自动。

  方法四：~/.claude/settings.json 配置白名单（我推荐）

  {
    "theme": "auto",
    "permissions": {
      "allow": [
        "Bash(*)",
        "Read(*)",
        "Write(*)",
        "Edit(*)",
        "Glob(*)",
        "Grep(*)"
      ]
    }
  }

  关于插件/SDK 调用 LLM 不弹窗的方法
方法一：SDK 调用时设置 permission_mode（推荐）
文档原文，在 ClaudeAgentOptions 里设置：


options = ClaudeAgentOptions(
    system_prompt="...",
    permission_mode='acceptEdits',   # 自动接受文件编辑，其余需要确认
    # 或者
    # permission_mode='bypassPermissions',  # 跳过所有权限提示（慎用）
    cli_path="/Users/xxx/.baidu-cc/baidu-cc/bin/claude"
)
三种 permission_mode 对比：

模式	效果
acceptEdits	自动接受文件编辑，其余需确认（推荐）
plan	计划模式，先规划后执行
bypassPermissions	跳过所有权限弹窗（慎用）
方法二：修改 settings.json 永久授权
编辑 ~/.claude/settings.json（全局）或 <项目>/.claude/settings.json（项目级）：


{
  "permissions": {
    "allow": [
      "Bash(*)",
      "Read(*)",
      "Write(*)",
      "Edit(*)",
      "mcp__icafe__get_card_by_id"
    ],
    "deny": []
  }
}
方法三：启动时临时授权（MCP 工具）

ducc --allowedTools "mcp__deepwiki__read_wiki_structure,mcp__deepwiki__read_wiki_contents"
方法四：非交互模式（-p 参数）

ducc -p "你的任务描述" --allowedTools "Bash,Read,Write"

claude --dangerously-skip-permissions
