# 退款配对识别模式

## 配对逻辑

退款配对需同时满足：
1. **金额匹配**：退款金额 ≤ 原消费金额（部分退款时金额更小）
2. **商户关联**：退款备注含原消费商户名关键词
3. **时间合理**：退款晚于消费，一般在 30 天内（特殊情况 90 天内）
4. **方向相反**：原消费为支出，退款为收入

## 汇报格式

```
【退款事件 #N】商户名 / 时间段
  原始消费：
    YYYY-MM-DD  账户  -金额  完整备注
  对应退款：
    YYYY-MM-DD  账户  +金额  完整备注
  配对依据：金额完全吻合 / 商户名匹配 / 时间差 N 天
  状态：完全退款 / 部分退款（差额 X 元，可能是运费/手续费）
  建议：抹平 / 请确认
```

## 常见退款场景

| 场景 | 特征 | 处理建议 |
|------|------|------|
| 购物全退 | 金额完全相等，7-15 天内 | 直接抹平 |
| 购物部分退 | 金额差 <50 元（运费/优惠差） | 保留差额作为实际支出 |
| 机票/酒店退 | 退款可能晚 15-30 天，可能有手续费 | 提示用户确认差额 |
| 预授权释放 | 两笔同账户，金额相等，间隔 1-7 天 | 直接抹平 |
| 优惠券返现 | 金额很小（1-20 元），备注含"返现/奖励" | 可忽略或计入"优惠收入" |

## 存疑情况

以下情况单独列出请用户判断：
- 时间差 >30 天
- 金额差额 >50 元且无明显解释
- 一笔消费对应多笔退款（可能是分批退）
- 退款账户与消费账户不同（跨平台退款）
