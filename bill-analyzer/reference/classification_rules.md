# 分类规则参考

> 本文件是通用参考，实际运行时以用户 Excel 中的分类 sheet 为准。
> 若用户没有自定义分类体系，可以此为初始模板。

## 一级分类

| 一级 | 说明 |
|------|------|
| 餐饮 | 所有吃喝消费 |
| 交通 | 出行相关 |
| 购物 | 实物商品 |
| 居家 | 房租水电及家庭日常 |
| 娱乐 | 休闲娱乐 |
| 医疗健康 | 医院、药店、健身 |
| 人情往来 | 礼金、份子钱 |
| 金融 | 保险、理财、利息 |
| 其他 | 无法归类的消费 |

## 二级分类示例

### 餐饮
- 工作餐（工作日午餐/外卖）
- 早餐
- 聚餐（朋友/家人聚餐）
- 奶茶咖啡
- 食材采购（超市、菜市场）

### 交通
- 通勤（上下班地铁/公交）
- 打车（非通勤出行）
- 长途出行（高铁/飞机/长途客运）
- 共享单车

### 购物
- 服装
- 数码电子
- 日用品
- 图书

### 居家
- 房租
- 水电煤气
- 网络/话费
- 家居用品

### 娱乐
- 演出/票务
- 旅游
- 游戏
- 在线订阅（流媒体/软件会员）

## 行为规律 → 分类映射

实际分类时，优先使用行为规律而非单纯商户名：

| 行为规律 | 推荐分类 |
|------|------|
| 工作日 07:30–09:00 + 公交/地铁 | 交通-通勤 |
| 工作日 07:30–09:00 + 小额餐饮 | 餐饮-早餐 |
| 工作日 11:30–13:00 + 餐饮 | 餐饮-工作餐 |
| 周末白天 + 餐饮 + 金额>80 | 餐饮-聚餐 |
| 23:00–02:00 + 生鲜/便利店 | 餐饮-食材采购 |
| 每月固定日 + 固定金额 | 居家-[类型] 或 金融-订阅 |
| 连续多天 + 异地消费 | 娱乐-旅游 |
| 周末打车 + 金额>50 | 交通-打车（聚会） |
